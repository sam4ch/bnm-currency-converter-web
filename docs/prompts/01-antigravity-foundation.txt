Критические правила реализации:
- Только .NET 8/BCL для Core/Infrastructure, без внешних обязательных runtime-пакетов. XML BNM: ValCurs с Date в DD.MM.YYYY и Valute/CharCode/Nominal/Value. Используй decimal и InvariantCulture для XML, проверь дату, номинал>0, курс>0, дубликаты; дополнительный корректный XML-код не делает весь документ невалидным. Нормализованный набор поддерживает MDL, EUR, USD, RON, GBP; MDL=1 добавляется после проверки, что ответ не пустой. Не превращай пустой ответ в успешный набор только с MDL.
- Сумма: положительная <=1000000000000, до четырёх знаков дроби, dot И comma принимаются; пробелы-группировка, экспонента, несколько разделителей, буквы, ноль/минус, переполнение запрещены. Русские сообщения. Формула amount*(ValueSource/NominalSource)/(ValueTarget/NominalTarget), округление AwayFromZero до 2 знаков ТОЛЬКО в конце. Переполнение — понятная ошибка. При одинаковых валютах вернуть исходную сумму, вообще не обращаться к источнику или кэшу, не выдумывать дату/источник/время.
- IClock и системная реализация по времени Кишинёва (Windows и Linux), DateOnly для календарных дат и DateTimeOffset для timestamp. Будущая/невозможная/пустая дата отклоняются.
- HttpClient с timeout 10s, поддержкой CancellationToken. Поиск: запрос выбранной даты, затем до 31 предыдущего календарного дня ТОЛЬКО при отсутствии публикации/пустом наборе. Неверный XML, HTTP-ошибка, обрыв связи или timeout останавливают поиск; не повторяй сетевую ошибку 32 раза. Если BNM сам вернул корректный более ранний курс, используй его настоящую дату, только не позже запрошенной.
- Кэш JSON в App_Data (путь задаётся конфигурацией): последний проверенный набор, timestamp и версия. Запись во временный файл в том же каталоге и атомарная замена под блокировкой; запись/чтение/конкуренция не повреждают хороший кэш. Плохой ответ не заменяет хороший. Существование кэша и дата проверяются заново после перезапуска/нового экземпляра сервиса; для тестов путь/HTTP/время подменяемы.
- При ошибке источника верни состояние CacheConfirmationRequired с датой и метаданными подходящего кэша; без явного cache approval НЕ рассчитывай молча. После согласия используй проверенный кэш с датой <= requestedDate и нужными валютами; кэш позже requestedDate нельзя. Старый курс сам по себе не запрещён, показывай дату/предупреждение. При подтверждении НЕ делай ещё один ненужный сетевой запрос. Ошибка записи кэша сохраняет успешный результат и отдельное предупреждение. Повреждённый/отсутствующий файл не роняет приложение.
- Раздели чистый калькулятор, валидацию, RateLookupService, orchestration ConversionService, BnmRateClient, XML parser и JsonCacheStore. Core не зависит от ASP.NET/HttpClient/Infrastructure. Provider реализации находятся в Infrastructure; DI в Web.
